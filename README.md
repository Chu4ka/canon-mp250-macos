# Canon PIXMA MP250 Printer Application для macOS

Прототип драйвера печати для USB-принтера Canon PIXMA MP250 (`04a9:173a`) на Mac с Apple Silicon и macOS 27 или новее. Стандартный диалог печати macOS отправляет Apple/PWG Raster локальной службе PAPPL по IPP. Gutenprint `bjc-MP250-series` формирует поток Canon BJRaster, а libusb передаёт его принтеру.

**Статус 0.2.1.** Печать на физическом MP250 для этой версии ещё предстоит проверить. Драйвер MP250 в Gutenprint 5.3.4 имеет статус `EXPERIMENTAL`.

## Установка из ZIP

Готовый ARM64 ZIP в `dist/` содержит бинарники, данные Gutenprint, скрипты установки и удаления и инструкцию на русском в DOCX и PDF. Для установки достаточно пароля администратора Mac. Интернет, Homebrew и Xcode Command Line Tools для готового пакета не нужны.

1. Подключите включённый принтер к Mac по USB.
2. Распакуйте ZIP и откройте Terminal. Пример для папки в Downloads:

   ```sh
   cd ~/Downloads/Canon-MP250-Driver-0.2.1-macOS-arm64
   sudo ./install.sh
   ```

3. Установщик запускает службу и проверяет ответ IPP. Если принтер подключён позже, фоновая служба повторяет поиск примерно каждые 30 секунд. Когда появится очередь `Canon_MP250`, откройте документ в Word и нажмите ⌘P.

Для обновления с 0.2.0 выполните `sudo ./install.sh` из распакованной папки 0.2.1. Предварительное удаление не требуется. Если имя `Canon_MP250` уже занято очередью другого драйвера, установщик сохранит её. Для автоматического добавления очереди этого проекта имя должно быть свободно.

## Проверка печати

В Microsoft Word нажмите ⌘P и выберите `Canon_MP250`. Для приёмки на физическом принтере возьмите документ из двух заметно различающихся страниц:

1. Напечатайте одну цветную копию и проверьте обе страницы и их порядок.
2. Напечатайте две копии в режиме «Оттенки серого» и проверьте, что вышли обе страницы каждой копии.
3. Отключите и снова подключите USB, подождите до 30 секунд и повторите печать.

Из Terminal можно напечатать PDF или DOC/DOCX:

```sh
mp250-print "/полный/путь/к/документу.pdf"
mp250-print "/полный/путь/к/документу.docx"
```

Для DOC/DOCX команда использует установленный Microsoft Word для экспорта во временный PDF. При первом вызове macOS может запросить разрешение Terminal управлять Word.

## Диагностика

Локальный веб-интерфейс показывает состояние принтера и заданий. Служба принимает подключения только на `127.0.0.1:8000`.

```sh
open http://127.0.0.1:8000/
lpstat -p Canon_MP250
lpstat -v Canon_MP250
/usr/local/bin/mp250-diag
/usr/local/bin/mp250-diag --open
```

URI очереди проекта — `ipp://127.0.0.1:8000/ipp/print/Canon_MP250_series_%28USB%29`. После обновления с 0.2.0 может сохраниться адрес с `localhost` и обычными скобками вокруг `USB`. Если очередь отсутствует, проверьте питание и USB. После переподключения можно запустить поиск вручную командой `sudo /usr/local/libexec/canon-mp250-autoadd`.

Первая команда `mp250-diag` выводит сведения об устройстве. Ключ `--open` дополнительно открывает интерфейс принтера и запрашивает IEEE-1284 Device ID. Ожидаются VID:PID `04a9:173a` и идентификатор с `MFG:Canon;MDL:MP250 series`. Если интерфейс занят, дождитесь завершения печати и повторите проверку.

Служба ведёт журнал на уровне `info`. Просмотр журналов через веб-интерфейс отключён.

```sh
sudo tail -n 100 /usr/local/var/log/canon-mp250-app.log
sudo tail -n 100 /usr/local/var/log/canon-mp250-launchd.log
sudo tail -n 100 /usr/local/var/log/canon-mp250-autoadd.log
```

## Удаление

В распакованной папке пакета выполните:

```sh
sudo ./uninstall.sh
```

Скрипт удаляет службы, очередь этого проекта, бинарники, данные Gutenprint и состояние печати. Одноимённая очередь другого драйвера и журналы сохраняются.

## Сборка из исходников

Нужны Mac с Apple Silicon, macOS 27 или новее и Xcode Command Line Tools (`xcode-select --install`). Скрипт закрепляет версии PAPPL 1.4.10, Gutenprint 5.3.4, libusb 1.0.30 и OpenSSL 3.5.8 и проверяет SHA-256 архивов. Интернет нужен для загрузки зависимостей при пустом кэше. Запускайте сборку от своего пользователя.

```sh
./scripts/bootstrap-deps.sh
make
make check
make smoke
make release
```

`make check` проверяет загрузку драйвера Gutenprint, LaunchDaemon-файлы и формат бинарников. `make smoke` запускает временный IPP-сервер на локальном порту 18080, проверяет завершение тестовых заданий с Apple/PWG Raster и записывает поток Canon в файл. Порт можно задать через `CANON_MP250_SMOKE_PORT`. Для проверки передачи по USB и выхода страниц нужен физический принтер.

Зависимости собираются во временном каталоге текущего пользователя. Если он очищен, повторите `./scripts/bootstrap-deps.sh`. Версию сборки задаёт файл [VERSION](VERSION). `make release` берёт инструкцию DOCX/PDF из `docs/` и формирует ZIP, файл контрольных сумм и архив соответствующих исходников `Canon-MP250-Driver-<версия>-source.tar.gz` в `dist/`. Команда `make install` собирает пакет, распаковывает его во временную папку и вызывает установщик из ZIP.

### Запуск для отладки

Для временного запуска службы без установки выполните:

```sh
prefix=$(/bin/sh ./scripts/deps-prefix.sh)
spool=$(mktemp -d "${TMPDIR:-/private/tmp}/canon-mp250-spool.XXXXXX")
STP_DATA_PATH="$prefix/share/gutenprint/5.3/xml" \
  ./build/bin/canon-mp250-app server \
  -o listen-hostname=127.0.0.1 \
  -o server-hostname=localhost \
  -o server-port=8000 \
  -o "spool-directory=$spool" \
  -o server-options=no-tls \
  -o log-level=info \
  -o log-file=-
```

Порт 8000 должен быть свободен. Остановите процесс сочетанием Ctrl+C. Для проверки рендеринга без USB используйте `make smoke`.

## Ограничения

- Поддерживается односторонняя печать на A4, Letter, Legal, 4×6 и 5×7. Драйвер обрабатывает цветной и серый растр.
- Сканирование и считывание уровня чернил вне возможностей проекта.
- Бинарники собраны без подписи Developer ID.
