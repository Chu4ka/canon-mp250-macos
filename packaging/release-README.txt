CANON PIXMA MP250 DRIVER — macOS 27 и новее / Apple Silicon
=========================================================

УСТАНОВКА

1. Включите Canon PIXMA MP250 и подключите его к Mac по USB.
2. Откройте Terminal. Введите cd и пробел, перетащите распакованную
   папку из Finder в окно Terminal и нажмите Return.
3. Выполните:

   sudo ./install.sh

4. Введите пароль администратора. При вводе символы не отображаются.
5. Установщик проверит, что локальная служба отвечает по IPP. Если вы
   подключили принтер позже, подождите до 30 секунд для появления
   очереди Canon_MP250.

Для обновления с 0.2.0 выполните ту же команду из папки нового пакета.
Очередь Canon_MP250 другого драйвера сохраняется. Для автоматического
добавления очереди этого проекта имя Canon_MP250 должно быть свободно.

ПЕЧАТЬ

В Microsoft Word нажмите ⌘P, выберите Canon_MP250 и нажмите «Печать».
Для проверки напечатайте двухстраничный документ в цвете, затем две
копии в оттенках серого. Переподключите USB и повторите печать.

Печать на физическом MP250 в версии 0.2.1 ещё предстоит проверить.
Бинарники собраны без подписи Developer ID. Сканирование вне
возможностей проекта.

ДИАГНОСТИКА

   lpstat -p Canon_MP250
   lpstat -v Canon_MP250
   /usr/local/bin/mp250-diag
   /usr/local/bin/mp250-diag --open

Веб-интерфейс службы на этом Mac — http://127.0.0.1:8000/.
Журналы доступны в Terminal:

   sudo tail -n 100 /usr/local/var/log/canon-mp250-app.log
   sudo tail -n 100 /usr/local/var/log/canon-mp250-launchd.log
   sudo tail -n 100 /usr/local/var/log/canon-mp250-autoadd.log

Если очередь не появилась после подключения и ожидания, проверьте
питание и USB, затем запустите поиск:

   sudo /usr/local/libexec/canon-mp250-autoadd

УДАЛЕНИЕ

Из распакованной папки пакета:

   sudo ./uninstall.sh

Журналы и одноимённая очередь другого драйвера сохраняются.
Подробная инструкция находится в папке «Документация».
